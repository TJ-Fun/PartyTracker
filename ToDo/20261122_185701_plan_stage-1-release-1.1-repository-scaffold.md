## 2. Current Roadmap Stage

Stage 1 establishes the technical foundation before feature development. Release 1.1 is the first release in that stage and has no dependencies.

## 3. Release Objective

Create a clean pnpm monorepo baseline with consistent tooling so later releases can add configuration, web/API foundations, database migrations, logging, notifications, CI/CD, and deployment pipelines without restructuring the repository.

## 4. Expected Final Outcome

After this release:

- The repository is a pnpm workspace with `apps/web`, `apps/api`, and `packages/shared`.
- TypeScript, ESLint, Prettier, and Vitest are configured.
- Root scripts can run lint, format, typecheck, and test across the workspace.
- The existing static Cloudflare placeholder remains deployable from `apps/web/public`.
- README and CONTRIBUTING documentation describe setup and commands.
- No application feature behavior is implemented yet.

## 11. Sequential Implementation Steps

### Step 1 — Create workspace manifests and directory structure

- **Complexity:** MEDIUM
- **Owner:** LLM
- **Objective:** Establish the pnpm monorepo and package boundaries.
- **Files affected:** `package.json`, `pnpm-workspace.yaml`, `apps/web/package.json`, `apps/api/package.json`, `packages/shared/package.json`, `.gitignore`, `.env.example`
- **Implementation tasks:**
  - Create `apps/web`, `apps/api`, and `packages/shared` directories.
  - Add root `package.json` with `private: true`, `packageManager`, `engines`, workspace scripts, and root dev dependencies.
  - Add `pnpm-workspace.yaml` covering `apps/*` and `packages/*`.
  - Add package manifests for web, API, and shared with names, private flags, `type: module`, and initial scripts.
  - Add `.gitignore` covering dependencies, builds, coverage, env files, Wrangler/SvelteKit output, logs, and `.idea/`.
  - Add `.env.example` with commented placeholders only.
- **Dependencies:** None.
- **Expected result:** pnpm recognizes three workspace packages.
- **Verification:** Run `pnpm install`; run `pnpm -r ls --depth -1` or equivalent workspace listing.
- **Definition of Done:** Workspace manifests are valid and install succeeds.
